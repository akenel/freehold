⚠ THE ONE RULE THAT MAKES SCANNING WORK
ONE ITEM · ONE LABEL · ONE PRODUCT

When a code changes (placeholder → real EAN, or a variant re-bin), hunt down and destroy the old label. Two labels for one item is exactly the “wrong price rung” mistake. This is the whole secret.

💰 Cost is private

You type the cost; it stays on the shop’s own box and never leaves. The shared catalog only knows what a thing is, never what it cost.

⏱️ Never stop the queue

Anything unfinished goes to the tidy-later worklist. The till never waits for paperwork. Sell first, clean later.

“It came up with stupid stuff” is not a broken scanner. Scanning is a lookup — it doesn’t guess. It just means: not captured yet (bind it, or print a label). The AI’s category guess on an unknown item is the part you confirm — a wrong guess is fine, you tick the right one.
Goal: after ~10–15 shop-days the moving assortment is captured — then “scan → it works.” 🐺 build the catalog, own the catalog
